# ANIK Live Hardware Monitor Toolkit

เครื่องมือมอนิเตอร์ฮาร์ดแวร์สำหรับ **Windows** ที่ทำงานเป็นเมนูในหน้าต่าง cmd ดู CPU / GPU / RAM / Disk / Network แบบเรียลไทม์ ตรวจอุณหภูมิพร้อมสีแจ้งเตือน บันทึก log เป็น CSV พร้อมสรุป min / avg / max และตรวจสุขภาพแบตเตอรี่กับดิสก์ ทั้งหมดอยู่ในไฟล์สคริปต์ 2 ไฟล์ **ไม่ต้องติดตั้ง ไม่ต้องใช้อินเทอร์เน็ต**

> **English summary:** A menu-driven, portable hardware monitor for Windows, made of one `.bat` and one `.ps1` file (no installation, no network access).
> It shows live CPU / GPU / RAM / disk / network usage with top processes, color-coded load and temperature alerts (green / yellow / red), CSV performance logging with min / avg / max summary, a system report, battery report and disk health.
> Requires Windows 10 (1709+) or Windows 11 for all features. Not supported on Linux or macOS. The documentation below is in Thai.

## ภาพรวม

**ANIK Live Hardware Monitor Toolkit** คือชุดสคริปต์ขนาดเล็กที่ช่วยให้เห็นสภาพเครื่อง Windows ได้เร็วจากหน้าต่างเดียว โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

ประกอบด้วยไฟล์ 2 ไฟล์ที่ต้องอยู่ในโฟลเดอร์เดียวกัน

| ไฟล์ | หน้าที่ |
|---|---|
| `ANIK_Monitor.bat` | ตัวเปิดโปรแกรมและเมนูหลัก (กดเลข 1-9 เพื่อเลือกฟังก์ชัน) |
| `ANIK_Monitor.ps1` | โค้ด PowerShell ที่ดึงข้อมูลและแสดงผลจริง |

### ฟังก์ชันทั้งหมด

| เมนู | ฟังก์ชัน | สรุปสั้น ๆ |
|---|---|---|
| **[1]** | Live Monitor | CPU / GPU / RAM แบบ live พร้อมแถบและสี, ความเร็ว Disk และ Network, พื้นที่ดิสก์, Top 5 โปรเซสที่ใช้ CPU และ RAM |
| **[2]** | System Information | ชื่อเครื่อง, Windows รุ่นไหน, CPU กี่คอร์, RAM เท่าไร |
| **[3]** | Disk Usage | พื้นที่ใช้ไปและเหลือของแต่ละไดรฟ์ |
| **[4]** | Network Information | อะแดปเตอร์ที่เชื่อมต่ออยู่, ความเร็วลิงก์, IPv4, Gateway, DNS |
| **[5]** | Save System Report | บันทึกรายงานข้อมูลเครื่องเป็นไฟล์ `.txt` ลง Desktop |
| **[6]** | Exit | ออกจากโปรแกรม |
| **[7]** | Temperature + Load Alerts | อุณหภูมิและโหลดของเครื่อง แสดงเป็นสีเขียว / เหลือง / แดงตามระดับ |
| **[8]** | Record Performance Log | บันทึกค่าต่อเนื่องเป็นไฟล์ CSV แล้วสรุป min / avg / max |
| **[9]** | Battery Report + Disk Health | สุขภาพแบตเตอรี่ (พร้อมรายงาน HTML จาก Windows) และสุขภาพดิสก์ |

### หลักการออกแบบ

- **พกพาได้ (portable):** คัดลอกสองไฟล์ไปวางที่ไหนก็รันได้ ไม่ต้องติดตั้งหรือแก้ระบบ
- **อ่านได้ทุกบรรทัด:** เป็นไฟล์ข้อความธรรมดา เปิดตรวจด้วย Notepad ได้ว่าทำอะไรบ้างก่อนรัน
- **ไม่เชื่อมต่ออินเทอร์เน็ต:** โค้ดไม่มีการส่งข้อมูลออกนอกเครื่อง
- **อ่านอย่างเดียวเป็นหลัก:** ไม่แก้ registry ไม่เปลี่ยนการตั้งค่าระบบ มีเพียงการเขียนไฟล์รายงานหรือ log ลง Desktop เมื่อคุณสั่งเท่านั้น
- **สีหลักเป็นสีขาว:** ข้อความปกติเป็นสีขาว มีสีเฉพาะส่วนที่เป็นการแจ้งเตือนระดับ (เขียว / เหลือง / แดง)

## ทำไมควรใช้และต่างจาก Task Manager อย่างไร

### ตำแหน่งของเครื่องมือนี้

เครื่องมือนี้ **ไม่ได้มาแทน Task Manager** Task Manager ยังดีกว่าในเรื่องกราฟย้อนหลัง การดูรายละเอียดรายโปรเซส การปิดโปรแกรมที่ค้าง และการจัดการ Startup / Services เครื่องมือนี้ถูกออกแบบมา **เสริมในงานที่ Task Manager ไม่ได้ทำ** คือการบันทึก การสรุปผล การแจ้งเตือนด้วยสี และการตรวจสุขภาพฮาร์ดแวร์ในที่เดียว

### เปรียบเทียบ

| หัวข้อ | Task Manager | ANIK Toolkit |
|---|---|---|
| ดู CPU / RAM / GPU / Disk / Network แบบ live | ✅ มีกราฟ | ✅ แบบข้อความและแถบ |
| กราฟย้อนหลัง | ✅ | ❌ |
| รายละเอียดรายโปรเซส / ปิดโปรแกรม / Startup / Services | ✅ | ❌ (มีเฉพาะ Top 5 ที่ใช้ CPU และ RAM) |
| **บันทึกค่าต่อเนื่องเป็น CSV** | ❌ | ✅ |
| **สรุป min / avg / max หลังบันทึก** | ❌ | ✅ |
| **สีแจ้งเตือนตามระดับ ปรับเกณฑ์เองได้** | ❌ | ✅ |
| อุณหภูมิ CPU และดิสก์ | ❌ | ⚠️ บางส่วน (ดูหัวข้อข้อจำกัด) |
| อุณหภูมิ GPU | ⚠️ บางเวอร์ชันแสดงได้ | ✅ เฉพาะการ์ด NVIDIA |
| **สถานะสุขภาพดิสก์** (Healthy / Warning / Unhealthy) | ❌ | ✅ |
| **สุขภาพแบตเตอรี่เทียบความจุตอนใหม่** | ❌ | ✅ พร้อมรายงาน HTML จาก Windows |
| **รายงานข้อมูลเครื่องเป็นไฟล์ในคลิกเดียว** | ❌ | ✅ |
| Disk + Network + Top โปรเซสในหน้าจอเดียว | ❌ (แยกแท็บ) | ✅ |
| ติดตั้ง / พกพา | มีมากับ Windows | ✅ คัดลอก 2 ไฟล์ก็ใช้ได้ |
| ตรวจสอบโค้ดก่อนใช้ได้ | ❌ | ✅ ข้อความธรรมดา |

### เหมาะกับงานแบบไหน

1. **เครื่องช้าเป็นบางช่วง** เริ่มบันทึก log [8] แล้วทำงานตามปกติ จากนั้นดูตัวเลขสูงสุด (Max) ของ CPU / Disk busy / RAM ในไฟล์สรุปว่าเกิดอะไรขึ้นตอนเครื่องช้า โดยไม่ต้องนั่งเฝ้าหน้าจอ
2. **ตรวจเครื่องมือสองก่อนซื้อ** เมนู [9] บอกสุขภาพแบตเตอรี่เป็น % ของความจุตอนใหม่ และสถานะสุขภาพดิสก์ ซึ่งดูจาก Task Manager ไม่ได้
3. **งานซัพพอร์ตและร้านซ่อม** เมนู [5] สร้างรายงานข้อมูลเครื่องเป็นไฟล์เดียวเก็บเป็นหลักฐานก่อนและหลังซ่อมได้ และรันจาก USB โดยไม่ต้องติดตั้งอะไรลงเครื่องลูกค้า
4. **ดูภาพรวมเครื่องเร็ว ๆ** หน้า [7] บอกว่า "โอเค / เริ่มน่าห่วง / สูงเกินไป" ด้วยสี ไม่ต้องอ่านตัวเลขทีละตัว
5. **ใช้ในหน้าต่าง cmd หรือ Windows Terminal** ไม่ต้องเปิดโปรแกรมแบบกราฟิก เบากว่าเมื่อต้องการแค่ดูตัวเลข

### เมื่อไรควรใช้เครื่องมืออื่นแทน

- ต้องการอุณหภูมิ CPU ที่แม่นยำ ความเร็วพัดลม หรือค่าแรงดันไฟ ให้ใช้โปรแกรมเฉพาะทาง เช่น **HWiNFO** หรือ **LibreHardwareMonitor**
- ต้องการกราฟย้อนหลังและการวิเคราะห์ละเอียด ให้ใช้ **Performance Monitor (perfmon)** หรือ **Resource Monitor** ที่มีมากับ Windows
- ต้องการตรวจ SMART ของดิสก์แบบเจาะลึก ให้ใช้ **CrystalDiskInfo** หรือเครื่องมือของผู้ผลิตดิสก์

## ระบบปฏิบัติการที่รองรับ

> ตารางนี้เป็นการประเมินจากข้อกำหนดของคำสั่งและ API ที่สคริปต์ใช้ **ไม่ใช่ผลการทดสอบ** ผลทดสอบจริงดูที่หัวข้อ "สภาพแวดล้อมที่ทดสอบแล้ว" ด้านล่าง

| ระบบปฏิบัติการ | สถานะ | หมายเหตุ |
|---|---|---|
| **Windows 11** | ✅ รองรับเต็มรูปแบบ | เป้าหมายหลัก |
| **Windows 10 เวอร์ชัน 1709 ขึ้นไป** | ✅ รองรับเต็มรูปแบบ | เป้าหมายหลัก |
| Windows 10 ก่อนเวอร์ชัน 1709 | ⚠️ บางส่วน | ค่า GPU load จะเป็น N/A เพราะไม่มีตัวนับ GPU Engine |
| Windows Server 2016 / 2019 / 2022 / 2025 | ⚠️ ส่วนใหญ่ใช้ได้ | ค่า GPU, แบตเตอรี่ และอุณหภูมิมักไม่มี (เป็นเรื่องปกติของเซิร์ฟเวอร์) |
| Windows 8.1 / Server 2012 R2 | ⚠️ ไม่รับประกัน | บางคำสั่ง (เช่น `Get-ComputerInfo`) และ GPU load ใช้ไม่ได้ |
| Windows 7 / Vista / XP | ❌ ไม่รองรับ | ไม่มีคำสั่งที่จำเป็น เช่น `Get-NetAdapter` |
| Windows บน ARM64 | ❓ ยังไม่ทราบ | น่าจะใช้ได้เพราะใช้ Windows PowerShell 5.1 แต่ไม่ได้ทดสอบ |
| **Linux / macOS** | ❌ ไม่รองรับ | ใช้ไฟล์ `.bat`, WMI/CIM และคำสั่งเฉพาะ Windows |

### ข้อกำหนดอื่น ๆ

- **Windows PowerShell 5.1** (`powershell.exe`) มาพร้อม Windows 10 และ 11 อยู่แล้ว ไม่ต้องติดตั้ง PowerShell 7 เมนู [5] ต้องใช้ 5.1 เพราะเรียก `Get-ComputerInfo`
- ต้องรันใน **cmd.exe หรือ Windows Terminal** ผ่านไฟล์ `.bat` ไม่รองรับ PowerShell ISE
- **ไม่ต้องใช้สิทธิ์ Administrator** สำหรับการใช้งานทั่วไป แต่บางค่าต้องใช้ (ดูหัวข้อข้อจำกัดเรื่องอุณหภูมิดิสก์)
- การ์ดจอ **NVIDIA** ต้องลงไดรเวอร์ให้มีโปรแกรม `nvidia-smi` จึงจะอ่านอุณหภูมิ GPU และ VRAM ที่ใช้จริงได้
- ถ้าเครื่องใช้นโยบายล็อก PowerShell เช่น Constrained Language Mode, AppLocker หรือ WDAC สคริปต์อาจทำงานไม่ได้ (ดูหัวข้อข้อควรระวัง)

## เริ่มใช้งานอย่างรวดเร็ว

1. **ดาวน์โหลด** กดปุ่ม **Code > Download ZIP** บนหน้า GitHub นี้ (หรือใช้ `git clone`)
2. **แตกไฟล์ ZIP** ให้ได้โฟลเดอร์ที่มี `ANIK_Monitor.bat` และ `ANIK_Monitor.ps1` อยู่ด้วยกัน อย่ารันจากภายในหน้าต่างพรีวิว ZIP โดยตรง
3. **ปลดบล็อกไฟล์ (ถ้ามี)** ถ้าดาวน์โหลดมาจากอินเทอร์เน็ต Windows อาจติดป้ายว่าไฟล์มาจากภายนอก ให้คลิกขวาที่ไฟล์ ZIP ก่อนแตกไฟล์ เลือก **Properties** แล้วติ๊ก **Unblock** ถ้ามีตัวเลือกนี้
4. **ดับเบิลคลิก `ANIK_Monitor.bat`** จะเห็นเมนู กดตัวเลข 1-9 เพื่อเลือกได้ทันที (ไม่ต้องกด Enter)
5. ถ้าเจอหน้าต่าง **"Windows protected your PC"** (SmartScreen) ให้กด *More info* แล้ว *Run anyway* เฉพาะเมื่อคุณเชื่อถือแหล่งที่มา และควรเปิดไฟล์ทั้งสองด้วย Notepad ตรวจก่อนรัน
6. ถ้าต้องการอุณหภูมิดิสก์ ให้คลิกขวาที่ `ANIK_Monitor.bat` แล้วเลือก **Run as administrator**

### รันตรงจากบรรทัดคำสั่ง (ไม่ผ่านเมนู)

เรียกฟังก์ชันใดฟังก์ชันหนึ่งตรง ๆ ได้ เหมาะกับการเขียนสคริปต์ต่อ

```
powershell -NoProfile -ExecutionPolicy Bypass -File ANIK_Monitor.ps1 -Action Monitor
powershell -NoProfile -ExecutionPolicy Bypass -File ANIK_Monitor.ps1 -Action Log -Minutes 30 -IntervalSec 5
```

| พารามิเตอร์ | ค่าที่ใช้ได้ | ความหมาย |
|---|---|---|
| `-Action` | `Monitor` `SysInfo` `Disk` `Network` `Report` `Temp` `Log` `Health` | ฟังก์ชันที่ต้องการ (บังคับ) |
| `-Minutes` | 0-1440 (ค่าเริ่มต้น 5) | ใช้กับ `Log` เท่านั้น ความยาวการบันทึกเป็นนาที `0` = บันทึกจนกว่าจะกดปุ่ม |
| `-IntervalSec` | 1-60 (ค่าเริ่มต้น 2) | ใช้กับ `Log` เท่านั้น ระยะห่างระหว่างการเก็บข้อมูลเป็นวินาที |

## คู่มือการใช้งานแบบละเอียด

### การควบคุมพื้นฐาน

- เมนูหลักรับ **ปุ่มตัวเลข 1-9** โดยตรง กดปุ่มอื่นเครื่องจะส่งเสียงเตือนและไม่ทำอะไร
- หน้าจอ **live** ([1], [7], [8]) อัปเดตทุกประมาณ 2 วินาที กด **ปุ่มใดก็ได้** หรือ **Ctrl+C** เพื่อกลับเมนู (Ctrl+C ในหน้าเหล่านี้ไม่ได้ปิดโปรแกรม แต่ทำหน้าที่เป็นปุ่มกลับเมนู)
- หน้าจอแบบแสดงผลครั้งเดียว ([2], [3], [4], [5], [9]) จะรอให้กดปุ่มใดก็ได้ก่อนกลับเมนู

### [1] Live Monitor

หน้าจอนี้แสดงข้อมูลเรียงจากบนลงล่างดังนี้

| ส่วน | ความหมาย |
|---|---|
| **CPU** | โหลด CPU รวมทุกคอร์ (%) พร้อมแถบและสีตามระดับ |
| **GPU** | โหลดของ engine แบบ 3D ของ GPU ตัวที่ทำงานหนักที่สุด (%) |
| **RAM** | หน่วยความจำที่ใช้ (%) และจำนวน GB ที่ใช้ / ทั้งหมด |
| **THROUGHPUT** | ความเร็วอ่าน / เขียนดิสก์ รวมทุกดิสก์ และ % Busy (ดิสก์ยุ่งแค่ไหน) กับความเร็วดาวน์โหลด / อัปโหลดของเครือข่าย |
| **GPU INFORMATION** | ชื่อการ์ดจอและ VRAM |
| **DISK USAGE** | พื้นที่ที่ใช้ / ทั้งหมดของแต่ละไดรฟ์ พร้อมสีตามระดับ |
| **NETWORK ADAPTERS** | อะแดปเตอร์ที่เชื่อมต่ออยู่และความเร็วลิงก์ |
| **TOP 5 BY CPU** | 5 โปรแกรมที่ใช้ CPU มากที่สุด (% ในสเกลเดียวกับ Task Manager) |
| **TOP 5 BY RAM** | 5 โปรแกรมที่ใช้ RAM มากที่สุด (private working set) |

**ข้อควรรู้ในการอ่านค่า**

- **Disk Busy สูง แต่ MB/s ต่ำ** มักหมายถึงดิสก์ถูกใช้งานแบบอ่านเขียนไฟล์เล็ก ๆ จำนวนมาก (พบบ่อยใน HDD หรือช่วงที่โปรแกรมสแกนไวรัสทำงาน)
- **Top 5 รวมโปรเซสชื่อเดียวกันเข้าด้วยกัน** เช่น `chrome` ทุกหน้าต่างและแท็บถูกรวมเป็นแถวเดียว
- ค่าความเร็วใช้หน่วย **MB/s = MiB/s** (1 MB = 1,048,576 bytes) ตามที่ Windows รายงาน
- เฟรมแรกอาจช้ากว่าปกติเล็กน้อย เพราะต้องค้นหาข้อมูลการ์ดจอและดิสก์ครั้งแรก

### [2] System Information

แสดงชื่อเครื่อง ชื่อและเวอร์ชัน Windows (รวมหมายเลข build) สถาปัตยกรรม (64-bit / ARM64) ชื่อ CPU จำนวนคอร์ / เธรด และ RAM ทั้งหมด (GB)

### [3] Disk Usage

แสดงเฉพาะ **ไดรฟ์ในเครื่อง (fixed disk)** พื้นที่ใช้ไป เหลือ ทั้งหมด (GB) และ % ที่ใช้ ไม่รวมแฟลชไดรฟ์ USB ไดรฟ์ถอดได้ หรือไดรฟ์เครือข่าย

### [4] Network Information

แสดงเฉพาะอะแดปเตอร์ที่สถานะ **Up** ได้แก่ชื่ออะแดปเตอร์ ความเร็วลิงก์ IPv4 Default Gateway และ DNS server

> หน้านี้แสดงข้อมูลเครือข่ายภายในของคุณ ระวังเรื่องการแคปภาพไปโพสต์สาธารณะ

### [5] Save System Report

สร้างไฟล์ `ANIK_System_Report_วันที่_เวลา.txt` บน Desktop (รองรับกรณี Desktop ถูกย้ายไป OneDrive) ประกอบด้วยหัวข้อ SYSTEM, CPU, GPU, DISKS, NETWORK และ FULL DETAILS (ข้อมูลเต็มจาก `Get-ComputerInfo`) ใช้เวลาไม่กี่วินาที ถ้าบันทึกไม่สำเร็จจะแจ้งข้อผิดพลาดชัดเจน ไม่แจ้งว่าสำเร็จหลอก


### [7] Temperature + Load Alerts

หน้าจอนี้รวมสถานะ "ปกติ / เริ่มสูง / สูงเกินไป" ไว้ที่เดียว แบ่งเป็น 3 ส่วน

1. **LOAD** CPU, GPU (3D), RAM, Disk busy, VRAM (เฉพาะ NVIDIA) และการใช้พื้นที่ของแต่ละไดรฟ์ แต่ละแถวมีแถบ ตัวเลข และสถานะ OK / WARN / HIGH
2. **TEMPERATURE** อุณหภูมิที่อ่านได้จากเครื่อง (ดูแหล่งที่มาและข้อจำกัดด้านล่าง) ถ้าเครื่องไม่มีเซนเซอร์ที่ Windows อ่านได้ จะแจ้งตรง ๆ ว่าไม่พบเซนเซอร์
3. **OVERALL STATUS** สถานะที่แย่ที่สุดในบรรดาค่าทั้งหมดที่แสดง

แหล่งอุณหภูมิที่เป็นไปได้

| ชนิด | อ่านจาก | ข้อควรรู้ |
|---|---|---|
| System thermal zone (ACPI) | ตัวนับ Thermal Zone ของ Windows | เป็นเซนเซอร์ของบอร์ด/เฟิร์มแวร์ **ไม่ใช่อุณหภูมิแกน CPU เสมอไป** หลายเครื่อง โดยเฉพาะเดสก์ท็อป ไม่มีค่านี้ |
| GPU | `nvidia-smi` | เฉพาะการ์ด NVIDIA ที่ลงไดรเวอร์ |
| Disk | Storage Reliability Counter | ส่วนใหญ่ต้องรันแบบ Administrator และไดรฟ์ต้องรายงานค่านี้ |

### [8] Record Performance Log

บันทึกข้อมูลต่อเนื่องเพื่อดูย้อนหลังหรือวิเคราะห์อาการเครื่องช้า

1. เลือกความยาว: **1 นาที / 5 นาที / 15 นาที / 60 นาที / จนกว่าจะกดปุ่ม**
2. ระหว่างบันทึกจะเห็นเวลาที่ผ่านไป จำนวน sample และค่าปัจจุบันพร้อมสี
3. เมื่อครบเวลา หรือเมื่อกดปุ่มใดก็ได้ / Ctrl+C โปรแกรมจะ **บันทึกไฟล์** แล้วแสดงตารางสรุป **Min / Avg / Max** ของแต่ละค่า

ข้อมูลที่บันทึกในทุก sample: CPU %, GPU 3D %, RAM % และ GB, Disk busy %, ความเร็วอ่าน/เขียนดิสก์, ความเร็วดาวน์โหลด/อัปโหลด, อุณหภูมิ thermal zone และอุณหภูมิ GPU (ถ้ามี)

> **อย่าปิดหน้าต่างด้วยปุ่ม X ระหว่างบันทึก** ข้อมูลเก็บในหน่วยความจำและเขียนลงไฟล์ตอนจบการบันทึกเท่านั้น หากปิดหน้าต่างหรือไฟดับกลางคัน ข้อมูลจะหาย ให้หยุดด้วยการกดปุ่มใดก็ได้

**วิธีอ่านผลสรุป**

- **Max** บอกจุดสูงสุดที่เคยเกิด เหมาะกับการตามหาอาการวูบวาบชั่วขณะ
- **Avg** บอกภาพรวมตลอดช่วงที่บันทึก
- เปิดไฟล์ CSV ใน Excel แล้วสร้างกราฟจากคอลัมน์ `Timestamp` เพื่อดูว่าค่าพุ่งตอนไหน

### [9] Battery Report + Disk Health

**ส่วน Battery**

- แสดงเปอร์เซ็นต์ที่เหลือและสถานะ (กำลังชาร์จ / ใช้แบต ฯลฯ)
- แสดง **Health** = ความจุเต็มปัจจุบัน ÷ ความจุตอนผลิต เป็น % (ถ้าเครื่องรายงานค่านี้) และแสดงค่า mWh ทั้งสองค่า
- สร้างรายงาน HTML จากคำสั่ง `powercfg /batteryreport` บน Desktop แล้วเปิดในเบราว์เซอร์ให้อัตโนมัติ (มีประวัติการใช้งานและการเสื่อมของแบต)
- เครื่องที่ไม่มีแบตเตอรี่ (เดสก์ท็อป) จะแจ้งว่าไม่พบแบตเตอรี่

**ส่วน Disk Health**

- แสดงชื่อ ชนิด (SSD/HDD) บัส (NVMe/SATA/USB ฯลฯ) ขนาด และสถานะ **Healthy / Warning / Unhealthy**
- ถ้าอ่านได้ จะแสดงอุณหภูมิ การสึกหรอ (Wear %) และชั่วโมงที่ใช้งาน (Power-on hours)

## สีแจ้งเตือนและการปรับเกณฑ์

สีกำหนดจากค่าเทียบกับเกณฑ์ 2 ระดับ ค่าตั้งต้นเป็นค่ากลาง ๆ ที่ตั้งไว้ทั่วไป **ไม่ใช่มาตรฐานของผู้ผลิตฮาร์ดแวร์ตัวใด** ควรปรับให้เหมาะกับเครื่องของคุณ

| สี | สถานะ | ความหมาย |
|---|---|---|
| 🟢 เขียว | OK | ต่ำกว่าเกณฑ์เตือน |
| 🟡 เหลือง | WARN | ถึงเกณฑ์เตือน |
| 🔴 แดง | HIGH | ถึงเกณฑ์วิกฤต |
| ⚫ เทาเข้ม | N/A | ไม่มีข้อมูล |

| รายการ | WARN เมื่อ ≥ | HIGH เมื่อ ≥ |
|---|---|---|
| โหลด CPU / GPU / RAM / Disk busy | 60% | 85% |
| พื้นที่ดิสก์ที่ใช้ไป | 80% | 90% |
| อุณหภูมิ CPU / thermal zone | 70 °C | 85 °C |
| อุณหภูมิ GPU | 75 °C | 88 °C |
| อุณหภูมิดิสก์ | 50 °C | 65 °C |
| การสึกหรอ SSD (Wear) | 70% | 90% |
| สุขภาพแบตเตอรี่ (**ยิ่งต่ำยิ่งแย่**) | ต่ำกว่า 80% | ต่ำกว่า 60% |

### วิธีปรับเกณฑ์

1. เปิด `ANIK_Monitor.ps1` ด้วย Notepad (หรือ VS Code)
2. หาบล็อก `$Thresholds = @{ ... }` ใกล้ต้นไฟล์ แล้วแก้ตัวเลข `Warn` และ `Crit`
3. บันทึกไฟล์ **เป็น ASCII หรือ UTF-8 โดยไม่ใส่อักขระพิเศษ/ภาษาไทย** (ดูหัวข้อสำหรับผู้พัฒนา)

## หลักการทำงานและแหล่งข้อมูล

สคริปต์เรียกข้อมูลผ่านคลาส **CIM/WMI** ของ Windows เป็นหลัก ซึ่งใช้ชื่อคลาสที่ **ไม่ขึ้นกับภาษาของ Windows** (ต่างจาก `Get-Counter` ที่ชื่อ counter ถูกแปลตามภาษาระบบ) จึงทำงานได้ทั้ง Windows ภาษาไทยและภาษาอื่น

| ข้อมูล | แหล่งข้อมูล |
|---|---|
| โหลด CPU | `Win32_PerfFormattedData_PerfOS_Processor` (`_Total`) สำรองด้วย `Win32_Processor.LoadPercentage` |
| โหลด GPU | `Win32_PerfFormattedData_GPUPerformanceCounters_GPUEngine` เฉพาะ engine ชนิด 3D |
| RAM | `Win32_OperatingSystem` |
| VRAM | ค่า 64-bit จาก registry ของไดรเวอร์จอ ถ้าไม่มีจึงใช้ `Win32_VideoController.AdapterRAM` (ซึ่งเป็น 32-bit จึงจำกัดที่ราว 4 GB และจะระบุว่า "approx.") |
| ความเร็วดิสก์ | `Win32_PerfFormattedData_PerfDisk_PhysicalDisk` (`_Total`) |
| ความเร็วเครือข่าย | `Win32_PerfFormattedData_Tcpip_NetworkInterface` (ตัด loopback/tunnel) |
| Top โปรเซส | `Win32_PerfFormattedData_PerfProc_Process` (รวมตามชื่อโปรแกรม) |
| อุณหภูมิ thermal zone | `Win32_PerfFormattedData_Counters_ThermalZoneInformation` สำรองด้วย `MSAcpi_ThermalZoneTemperature` (ต้อง Admin) |
| อุณหภูมิ / VRAM ของ NVIDIA | โปรแกรม `nvidia-smi` |
| สุขภาพดิสก์ | `Get-PhysicalDisk` และ `Get-StorageReliabilityCounter` |
| แบตเตอรี่ | `Win32_Battery`, `BatteryStaticData` และ `BatteryFullChargedCapacity` (namespace `root/wmi`) และ `powercfg /batteryreport` |

**โปรแกรมภายนอกที่ถูกเรียกใช้** มีเพียง `powershell.exe`, `choice.exe`, `powercfg.exe` (เมนู [9]) และ `nvidia-smi.exe` (เฉพาะเครื่องที่มี) ทั้งหมดเป็นเครื่องมือของ Windows หรือของไดรเวอร์

## ข้อจำกัด

### 1) ด้านแพลตฟอร์ม

- ใช้ได้เฉพาะ **Windows** (ดูตารางด้านบน) ไม่มีเวอร์ชัน Linux / macOS
- ไฟล์ `.bat` และ `.ps1` **ต้องอยู่โฟลเดอร์เดียวกัน**
- รันใน PowerShell ISE ไม่ได้ ต้องรันผ่านไฟล์ `.bat`
- หน้าจอเป็น **ภาษาอังกฤษอย่างเดียว** เพราะ console ของ Windows แสดงภาษาไทยเพี้ยนได้ง่าย
- คำสั่งปรับขนาดหน้าต่าง (`mode con`) ใช้ไม่ได้ใน **Windows Terminal** หน้าต่างอาจเล็กไป ให้ขยายเอง ถ้าหน้าต่างเตี้ยกว่าเนื้อหา แถวล่างสุดจะถูกตัดออก (ไม่ทำให้โปรแกรมพัง)

### 2) อุณหภูมิ

- Windows **ไม่มีช่องทางมาตรฐานอ่านอุณหภูมิแกน CPU** ค่า "System thermal zone (ACPI)" เป็นเซนเซอร์ของบอร์ด/เฟิร์มแวร์ อาจไม่ตรงกับอุณหภูมิ CPU จริง บางเครื่องรายงานค่าคงที่หรือไม่รายงานเลย
- เดสก์ท็อปจำนวนมาก **ไม่มีค่าอุณหภูมิให้อ่านเลย** (โปรแกรมจะแจ้งตรง ๆ ว่าไม่พบเซนเซอร์)
- อุณหภูมิ GPU อ่านได้เฉพาะ **NVIDIA** (ผ่าน `nvidia-smi`) การ์ด AMD และ Intel ยังไม่รองรับ
- อุณหภูมิและ Wear ของดิสก์ ต้องรันเป็น **Administrator** และไดรฟ์ต้องรายงานค่าเหล่านี้ (ดิสก์ใน USB enclosure หรือบางชนิดของ RAID มักอ่านไม่ได้)
- ไม่มีความเร็วพัดลม แรงดันไฟ หรืออุณหภูมิรายคอร์ → ใช้ HWiNFO / LibreHardwareMonitor

### 3) GPU

- โหลด GPU นับเฉพาะ engine ชนิด **3D** งานที่ใช้ GPU ผ่าน engine ชนิดอื่น (เช่น compute/CUDA/AI, video encode/decode) **ไม่ปรากฏในค่านี้** อาจเห็นเป็น 0% ทั้งที่การ์ดทำงานอยู่
- ถ้าเครื่องมีหลาย GPU จะแสดง **ค่าของ engine ที่ยุ่งที่สุด** ไม่แยกรายการ์ด
- ต้องใช้ Windows 10 เวอร์ชัน 1709 ขึ้นไปและไดรเวอร์ WDDM 2.x ถ้าไม่มีจะขึ้น **N/A**
- VRAM ของการ์ดออนบอร์ด (ที่ใช้หน่วยความจำร่วมกับ RAM) มักขึ้น "N/A (shared memory)"
- บนเครื่องเสมือน (VM) ตัวนับ GPU และอุณหภูมิมักไม่มี

### 4) ความแม่นยำของตัวเลข

- ค่าอาจ **ไม่ตรงกับ Task Manager เป๊ะ ๆ** เพราะช่วงเวลาสุ่มตัวอย่างต่างกัน, การเลือก GPU engine ต่างกัน, และการใช้หน่วย MiB/s
- **CPU % ของ Top โปรเซส** หารด้วยจำนวน logical processor ที่ Windows รายงาน บนเครื่องที่มีเกิน 64 logical processors (เซิร์ฟเวอร์ขนาดใหญ่) ค่าอาจคลาดเคลื่อน
- โปรเซสที่เกิดและจบภายในรอบเดียว (สั้นกว่า 2 วินาที) อาจไม่ปรากฏ และรอบแรกของโปรเซสใหม่อาจแสดง 0%
- Top โปรเซสรวมตามชื่อโปรแกรม ไม่แยกตาม PID
- **ความเร็วเครือข่าย** รวมทุกอะแดปเตอร์ ยกเว้น loopback และ tunnel อะแดปเตอร์เสมือนที่ทำงานซ้อนกัน (เช่น Hyper-V, Docker, VPN บางชนิด) อาจทำให้ตัวเลขถูกนับซ้ำ
- เกณฑ์สีเป็นค่ากลาง ไม่ใช่ข้อกำหนดของผู้ผลิต

### 5) การบันทึก log

- เก็บข้อมูลในหน่วยความจำและเขียนไฟล์ตอนจบเท่านั้น ถ้าปิดหน้าต่างหรือไฟดับกลางคัน **ข้อมูลจะหาย**
- ช่วงเวลาระหว่าง sample จริงอาจนานกว่าที่ตั้ง (ขั้นต่ำ 2 วินาทีตามค่าเริ่มต้น และจะนานขึ้นถ้าเครื่องช้าหรือมีโปรเซสจำนวนมาก)
- เมนูกำหนดความยาวได้ 1 / 5 / 15 / 60 นาที หรือจนกดปุ่ม ถ้าต้องการช่วงอื่นหรือระยะห่างอื่น ให้เรียกผ่านบรรทัดคำสั่งด้วย `-Minutes` และ `-IntervalSec`
- ไม่มีการหมุนไฟล์ (rotation) การบันทึกที่ยาวมาก (หลายชั่วโมง) จะใช้หน่วยความจำเพิ่มตามจำนวน sample

### 6) สุขภาพแบตเตอรี่และดิสก์

- ค่า Health ของแบตเตอรี่ขึ้นกับว่าเครื่องรายงานความจุตอนผลิตและความจุปัจจุบันหรือไม่ ถ้าไม่ จะขึ้น N/A
- สถานะดิสก์ "Healthy" **ไม่ได้รับประกันว่าดิสก์จะไม่เสีย** ข้อมูลสำคัญต้องมีการสำรองเสมอ
- ดิสก์ที่ต่อผ่านอุปกรณ์ภายนอกหรือ RAID ฮาร์ดแวร์ อาจแสดงข้อมูลได้ไม่ครบ

### 7) ฟีเจอร์ที่ไม่มี

กราฟย้อนหลัง, ปิดโปรเซสที่ค้าง, จัดการ Startup / Services, ข้อมูลรายคอร์, ความเร็วพัดลม, การแจ้งเตือนด้วยเสียงหรืออีเมล, การทำงานเป็นเซอร์วิสเบื้องหลัง, การมอนิเตอร์เครื่องอื่นจากระยะไกล

## ข้อควรระวัง

### ความปลอดภัยและความน่าเชื่อถือ

- **อ่านโค้ดก่อนรันเสมอ** โดยเฉพาะเมื่อดาวน์โหลดจากแหล่งที่ไม่ใช่ผู้เผยแพร่ต้นทาง ทั้งสองไฟล์เป็นข้อความธรรมดา สคริปต์ใดก็ตามที่ถูกแก้ไขโดยคนอื่นอาจทำสิ่งอื่นได้ ดาวน์โหลดจากหน้า GitHub ทางการของโปรเจกต์นี้เท่านั้น
- ตัวเปิดโปรแกรมใช้ `-ExecutionPolicy Bypass` ซึ่ง **มีผลเฉพาะ process นั้น** ไม่เปลี่ยนนโยบายของเครื่อง ไม่ได้ข้ามนโยบายที่ผู้ดูแลระบบตั้งผ่าน Group Policy และเป็นรูปแบบที่โปรแกรมป้องกันไวรัสบางตัวเตือนเป็นเรื่องปกติ
- Windows SmartScreen / โปรแกรมป้องกันไวรัสอาจเตือนหรือบล็อกไฟล์ `.bat` ที่ดาวน์โหลดมา (false positive) อย่าปิดระบบป้องกันของเครื่อง ให้ตรวจโค้ดแล้วเพิ่มข้อยกเว้นเฉพาะโฟลเดอร์นี้หากเชื่อถือ
- **เครื่องในองค์กร:** นโยบายอาจห้ามรันสคริปต์ ถ้าเครื่องใช้ Constrained Language Mode, AppLocker หรือ WDAC สคริปต์อาจทำงานไม่ได้ ควรขออนุญาตผู้ดูแลระบบก่อนใช้งาน อย่าพยายามหลบนโยบาย

### ความเป็นส่วนตัว

- รายงานระบบ [5] อาจมี **ชื่อเครื่อง ชื่อผู้ใช้ ข้อมูลเจ้าของ และหมายเลขซีเรียล BIOS** ตรวจและลบก่อนส่งให้คนอื่นหรือแนบใน GitHub Issue
- หน้า [4] แสดง IP, Gateway และ DNS ของเครือข่ายภายใน ระวังเวลาแคปภาพไปแชร์
- ไฟล์ log CSV มีเวลาและพฤติกรรมการใช้เครื่อง ซึ่งอาจบอกช่วงเวลาที่คุณทำงานหรือไม่อยู่หน้าเครื่อง
- สคริปต์ **ไม่ส่งข้อมูลออกอินเทอร์เน็ต** ข้อมูลอยู่ในเครื่องจนกว่าคุณจะส่งต่อเอง

### การใช้งานและการตีความ

- ผลที่ได้เป็น **ข้อมูลประกอบการวินิจฉัย ไม่ใช่การรับประกัน** อย่าตัดสินใจเปลี่ยนฮาร์ดแวร์หรือสรุปว่าเครื่องเสียจากเครื่องมือนี้อย่างเดียว ควรยืนยันด้วยเครื่องมือเฉพาะทางหรือช่างผู้เชี่ยวชาญ
- อุณหภูมิจาก ACPI thermal zone อาจไม่ใช่อุณหภูมิ CPU จริง ถ้าสงสัยว่าเครื่องร้อนเกิน ให้ตรวจด้วย HWiNFO / LibreHardwareMonitor ด้วย
- **สำรองข้อมูลเสมอ** แม้สถานะดิสก์เป็น Healthy
- แถบสี OK ไม่ได้แปลว่าเครื่องไม่มีปัญหา และ HIGH ชั่วคราวระหว่างทำงานหนักเป็นเรื่องปกติ

### ผลกระทบต่อเครื่อง

- โปรแกรมค้นข้อมูลจากระบบทุก ~2 วินาที ใช้ CPU เล็กน้อย (โดยเฉพาะตัวนับ GPU และโปรเซสเมื่อมีโปรเซสจำนวนมาก) บนเครื่องที่ช้ามากอาจมีผลต่อการวัดเล็กน้อย และจะเห็น `powershell.exe` ในรายการโปรเซสของตัวเองเสมอ
- รายงานแบตเตอรี่ [9] จะเปิดเบราว์เซอร์อัตโนมัติ
- เมนู [8] หลายชั่วโมงใช้หน่วยความจำเพิ่มตามจำนวน sample (เล็กน้อยสำหรับการบันทึกเป็นชั่วโมง)

### การแก้ไขโค้ด

- บันทึก `ANIK_Monitor.ps1` ให้เป็น **ASCII ล้วน** (หรืออย่างน้อยห้ามมีภาษาไทย/อักขระพิเศษ) เพราะ Windows PowerShell 5.1 อ่านไฟล์ UTF-8 ที่ไม่มี BOM เป็น ANSI และตัวอักษรจะเพี้ยน
- ไฟล์ `.bat` ควรเป็นบรรทัดแบบ **CRLF** ถ้าถูกแปลงเป็น LF อาจทำให้ `goto` / label ทำงานผิดพลาด

### ต้องการแจ้งปัญหา (Issue)

โปรดระบุข้อมูลต่อไปนี้ เพื่อให้ตรวจสอบได้เร็ว

1. เวอร์ชัน Windows (กด `Win + R` พิมพ์ `winver`)
2. เวอร์ชัน PowerShell (รัน `powershell -NoProfile -Command "$PSVersionTable.PSVersion"`)
3. ประเภทเครื่อง (โน้ตบุ๊ก / เดสก์ท็อป / VM) และยี่ห้อ GPU
4. เมนูที่ใช้ ข้อความ error หรือภาพหน้าจอ
5. **ลบข้อมูลส่วนตัว** (ชื่อเครื่อง ชื่อผู้ใช้ IP ซีเรียล) ออกจากข้อความหรือภาพก่อนโพสต์

## สำหรับผู้พัฒนาและผู้ร่วมพัฒนา

### โครงสร้างโปรเจกต์

```
.
├── ANIK_Monitor.bat    เมนู / ตัวเปิดโปรแกรม (CRLF, ASCII)
├── ANIK_Monitor.ps1    ตรรกะทั้งหมด (CRLF, ASCII)
└── README.md
```

ภายใน `ANIK_Monitor.ps1` แบ่งเป็นส่วน (region) ได้แก่ Settings (เกณฑ์และสี), Small helpers, Alert levels and colored text, Data collectors, Live view engine และส่วนของแต่ละเมนู ฟังก์ชันที่วาดหน้าจอ live (`Get-MonitorLines`, `Get-TempLines`, `Get-LogLines`) ส่งข้อความกลับไปให้ `Invoke-LiveView` วาดซ้ำทุกรอบ ถ้าจะเพิ่มหน้าจอ live ใหม่ ให้เขียนฟังก์ชันที่คืนค่าเป็นชุดข้อความแล้วเรียกผ่าน `Invoke-LiveView -Builder '<ชื่อฟังก์ชัน>'`

### ข้อกำหนดในการแก้ไขโค้ด

- ไฟล์ต้องเป็น **ASCII ล้วน** และ **CRLF**
- ถ้าใช้ Git ให้เพิ่มไฟล์ `.gitattributes` เพื่อกันไม่ให้ Git แปลงตอนจบบรรทัดเป็น LF

  ```
  *.bat text eol=crlf
  *.ps1 text eol=crlf
  ```

- ใช้ฟีเจอร์ที่ Windows PowerShell 5.1 รองรับเท่านั้น (ห้ามใช้ไวยากรณ์เฉพาะ PowerShell 7 เช่น `?:`, `&&`)
- ห้ามเพิ่มการเชื่อมต่ออินเทอร์เน็ตหรือการส่งข้อมูลออกนอกเครื่อง เพราะเป็นหลักการของโปรเจกต์
- ทดสอบอย่างน้อยบน Windows 10 และ Windows 11 และระบุผลในหัวข้อ "สภาพแวดล้อมที่ทดสอบแล้ว"

### แนวทางพัฒนาต่อที่น่าสนใจ

รองรับอุณหภูมิ GPU ของ AMD / Intel, รายงานเป็น HTML, เลือกช่วงเวลาบันทึก log เองในเมนู, เมนูภาษาไทย (ต้องจัดการ encoding และฟอนต์ของ console), และการแยกอุณหภูมิรายคอร์ผ่านไลบรารีภายนอกแบบเลือกติดตั้งได้

**ข้อสงวนสิทธิ์:** ซอฟต์แวร์นี้เผยแพร่ **"ตามสภาพ" (as is) โดยไม่มีการรับประกันใด ๆ** ทั้งโดยชัดแจ้งและโดยนัย ผู้พัฒนาไม่รับผิดชอบต่อความเสียหายใด ๆ ที่เกิดจากการใช้งานหรือการตีความผลลัพธ์ ผู้ใช้ควรตรวจสอบโค้ดและใช้ด้วยความรับผิดชอบของตนเอง
